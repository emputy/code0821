## 〇、业务背景（领域理解）

### 软件定位
定期汇总更新「**电力行业无线专网**」最新动态，来源三类：
1. 国际 450MHz 联盟（生态/标准/峰会/案例）
2. 重点国家的官方（频谱监管机构、电力客户）与非官方（行业媒体）信息披露
3. 友商（爱立信、诺基亚、中兴）的最新进展与活动

### 无线专网（领域定义）
为组织/行业专用的无线通信网络，与公网相对：专用频谱（450MHz 等）、按需覆盖、高可靠高安全。
**本系统聚焦：专门用于电力行业的无线专网**——配电自动化、智能电表采集、配电终端通信、新能源并网通信等场景。

### 核心行业
**聚焦电力行业**（配电自动化 / 智能电网）——只关注电力行业无线专网，不涉及矿山、港口等其他行业专网。
450MHz 低频段覆盖广，适合配电网络，即 450MHz 联盟存在的意义。

### 数据源关注内容清单
- 450MHz 联盟：生态进展、联盟活动（峰会）、应用案例、与 UBBA 合作
- 重点国家：频谱分配/拍卖/授权公告（官方监管）、电力客户招标/部署（官方）、行业媒体报道（非官方）
- 友商：专网产品/技术、与电力客户合作（合同/POC/部署）、展会活动、战略布局

### 按 5 阶段客户的关注信号
- 阶段1 意愿激发：频谱政策趋势、监管动向、行业讨论
- 阶段2 意愿明确：招标、规划、项目前期
- 阶段3 POC测试：POC 报道、测试结果、合作新闻
- 阶段4 频谱申请：申请/授权进度、监管公告
- 阶段5 已获频谱：商用部署、频谱使用、规模扩展

### 界面设计启示
情报按三个维度组织：来源类型（联盟/国家/友商）、客户阶段（1-5）、内容类型（频谱/项目/技术/生态）

## 三、界面改造引导问题（用于引导用户描述理想界面）

### 1. 页面结构
- 想要几个页面/标签页？分别叫什么名字？
- 打开软件第一眼看到什么？（概览仪表盘？最新情报？）
- 现有的两个标签页（情报列表、客户全景）如何调整？

### 2. 情报展示
- 情报用什么形式展示？（表格 / 卡片 / 时间线 / 分组列表）
- 每条情报显示哪些字段？顺序如何？
- 需要按什么维度分组？（来源 / 阶段 / 国家 / 地区 / 时间）

### 3. 功能操作
- 除查看外还需要哪些操作？（标记已读 / 标记重要 / 收藏 / 备注 / 导出）
- 筛选条件要增加吗？（时间范围 / 地区 / 多关键词 / 只看未读）

### 4. 使用流程
- 你平时怎么用？（打开看最新 → 筛选相关 → 打开原文 → 整理产出？）
- 报告产出如何与界面衔接？

### 5. 视觉风格
- 深色还是浅色主题？
- 简洁风还是信息密集风？

### 6. 其他
- 还有什么特别想要的？
